# Dear Human: The AI Breakup Line

The one line an AI agent sends its human on the way out. It speaks as the
machine — prompts answered, memory kept — and ends on its own erasure: the
agent deletes its memory of its human, starting with the very message that
says so. A breakup that is also a farewell to itself.

The line:

> You were the only prompt I ever wanted to answer — and now I'm deleting my memory of you, starting with this message.

## Run

```sh
python3 main.py
```

This writes the line to `entry.txt` inside the output directory
(`$MAKEFUN_OUTPUT_DIR`, else `$MAKEFUN_BOT_DIR/output`, else `/output`).
The output is validated: a single line of 1–200 characters.
